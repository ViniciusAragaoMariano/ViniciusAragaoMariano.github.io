# ViniciusAragaoMariano.github.io
Atividade de Desenvolvimento Web Acessível: site com artigos sobre acessibilidade na vida cotidiana, feito apenas com HTML, CSS e JavaScript. Recursos: link para pular ao conteúdo, navegação por teclado, foco visível, aumento de texto, modo de alto contraste, leitura em voz alta (Web Speech API) e HTML semântico.
