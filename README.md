# ViniciusAragaoMariano.github.io
# Acessível no Dia a Dia

Site educativo com artigos sobre acessibilidade na vida cotidiana, feito apenas com HTML, CSS e JavaScript, seguindo a WCAG 2.2.

**Site publicado:** https://viniciusaragaomariano.github.io

## Páginas
- Início
- Visão: leitores de tela e contraste
- Audição: legendas, Libras e texto
- Mobilidade: navegação por teclado
- Cognição: linguagem simples e neurodiversidade
- Recursos: leis, normas e ferramentas

## Recursos de acessibilidade
- Link para pular ao conteúdo e navegação completa por teclado
- Foco visível e áreas de clique de pelo menos 44 px
- Aumento e redução do texto
- Modo de alto contraste
- Leitura em voz alta (Web Speech API)
- HTML semântico, tabelas com legenda e idioma definido (pt-BR)
